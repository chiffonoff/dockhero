# DockHero

Macの Dock の上で遊べる、小さな放置RPG。

このリポジトリには、配布済みの DockHero が自動更新で取りに来るゲーム本体（`index.html`）と、
最新版の情報（`version.json`）を置いています。

- `version.json` の `build` を上げて `sha256` を更新すると、各自の DockHero が起動時に新しい版へ入れ替わります。
- 自動で更新されるのはゲーム画面だけです。Mac側の本体（窓を出す部分）は zip で配布します。

## 全員のレベルを1に戻す（シーズンリセット）

`index.html` の `const SAVE_EPOCH = 2;` の数字を1つ上げて公開すると、次に起動したとき全員のセーブが
リセットされ、Lv1 からのスタートになります（名前・フレンド・フレンドコードは残ります）。
